Portfolio optimization excel file contains all info.
YFtoExcel File used to pull ticker data. 

Description:
Efficient Frontier Estimation and optimization of portfolio weights provided a restricted universe of ERISA eligible funds across a limited set of asset classes. 

Created a strategic asset allocations provided a set of constraints and simulated the returns of the SAA portfolio using a monte carlo method reflecting the returns and volatility of the dot-com bubble. 

Used Yfinance and python to download publicly available index data, and assumed that all funds were closet indexers. 

given the limited data, assumed that the expected return of the funds would equal the running average from 2016-2026, removing the effect of the COVID pandemic for consistency across datapoints.
